Автоматизация разбора откликов на hh.ru

Критерии отбора, логика работы AI-скоринга и последовательность внедрения — от подключения API до уведомления менеджера о готовом шортлисте.

Критерии отбора

Жёсткие критерии проверяются кодом до обращения к AI и решают судьбу отклика без исключений. Мягкие критерии оценивает AI с опорой на базу знаний о компании и позиции, только у кандидатов, прошедших жёсткий фильтр.

Жёсткие критерии

Да / нет · отсеивают до AI
  • Релевантность опыта позицииmust
  • Локация / формат работыmust
  • Зарплатные ожидания в вилкеmust
  • Обязательные hard skills присутствуютmust

Мягкие критерии

Оценивает AI, взвешенный score
  • Глубина обязательных навыков40%
  • Логика карьеры, нет тревожных паттернов20%
  • Качество сопроводительного письма20%
  • Софт-скиллы по тексту резюме20%

Схема процесса

Отклик проходит два фильтра подряд: сначала формальный (код), затем смысловой (AI). До ручного просмотра менеджера доходят только средние по score кандидаты — явные да и явные нет система решает сама.

Роадмап внедрения

Подготовка

Собираем базу знаний и получаем техническую основу для остальных этапов.

  • База знаний: компания, реальные обязанности позиции, стоп-факторы, вилка зарплаты, портрет идеального кандидата
  • OAuth-доступ к hh.ru API, регистрация приложения на dev.hh.ru
  • Финальный список жёстких и мягких критериев под конкретную вакансию

Забор откликов и жёсткий фильтр

Отклики автоматически попадают в систему и проходят первый, формальный отсев без AI.

  • Опрос API на новые отклики по вакансии (n8n/Make)
  • Забор резюме кандидата в структурированном виде
  • Жёсткие фильтры кодом: релевантность, локация, зарплата, hard skills

AI-скоринг

Кандидаты, прошедшие жёсткий фильтр, получают оценку по мягким критериям.

  • Промпт: база знаний + критерии с весами + резюме → структурированный JSON-ответ
  • Пороговые решения: 8–10 шортлист, 5–7 ручной просмотр, ниже 5 отказ

Анкета и тестовое

Уточняем то, чего нет в резюме — но только у кандидатов с хорошим score.

  • Короткая форма под уточняющие вопросы (готовность к дате, скилл, отсутствующий в резюме)
  • Автоотправка ссылки через сообщение hh.ru API или email

CRM и уведомления

Результат всей цепочки становится видимым для менеджера.

  • Кандидат, score и вердикт AI — в Битрикс24 / Notion
  • Уведомление менеджеру в Telegram по каждому кандидату в шортлисте
  • Опционально: авто-отказ низким score с вежливым шаблоном

Калибровка

Сверяем решения AI с реальным выбором человека и донастраиваем систему.

  • Прогон первой партии реальных откликов
  • Сверка вердиктов AI с ручным решением менеджера, поиск расхождений
  • Корректировка весов критериев и промпта по итогам
